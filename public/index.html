Find homework posted only in Canvas Modules

Some classes post homework as PDFs in Modules (like HW1.pdf) instead of on the calendar. With a Canvas access token, Triton Tracker finds them and estimates due dates from when they were posted. The Triton Tracker Sync extension does this too, plus exact Gradescope dates.

  1. In Canvas, open Account → Settings.
  2. Under Approved Integrations, click + New Access Token. Purpose: "Triton Tracker"; pick an expiry date (e.g. end of quarter).
  3. Copy the token and paste it here.

⚠️ A token can do anything you can do in Canvas, so treat it like a password. It's saved only in this browser and sent to the Triton Tracker server just to read Canvas. It's never stored or logged there. You can delete it any time in Canvas → Settings.
